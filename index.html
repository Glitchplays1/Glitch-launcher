Neon glitch home screen for Android. Download the APK, then set Glitch Launcher as your Home app.

Download APK Install & set as home

Use this page: https://glitchplays1.github.io/Glitch-launcher/. If Download says no file, wait for the build to finish and refresh.

Install and set as home

  1. Open this page on your phone and tap Download APK.
  2. Allow installs from the browser if Android asks.
  3. Install Glitch Launcher.
  4. Settings → search Default apps → Home app → pick Glitch Launcher.
  5. Press Home. Swipe up on the CATCH lock screen to see your apps.
Built from the Glitch-launcher GitHub repo. Switch Home app back to stock before uninstalling.

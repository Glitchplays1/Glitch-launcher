CATCH

Neon glitch home screen for Android. Install the APK, then set Glitch Launcher as your default Home app so the lock and home layouts from the previews become your phone’s start screen.

Download APK Install & set as home

Put your real GlitchLauncher.apk in this same folder as index.html. The button looks for that filename. Only install APKs you built or trust. Unknown APKs can harm a phone.

1. Install the APK

  1. On your phone, open this page and tap Download APK.
  2. If Android blocks it, open Settings → Security (or the download banner) and allow installs from this browser.
  3. Open the downloaded file and tap Install.
  4. When it finishes, tap Open.

2. Change the home launcher

This is the step that actually replaces your current home screen.

  1. Open Settings.
  2. Search for Default apps (fastest on every brand).
  3. Tap Home app / Launcher.
  4. Choose Glitch Launcher.
  5. Press the Home button or swipe up from the bottom. The new CATCH layout should appear.

Brand shortcuts:

  • Pixel / stock Android: Settings → Apps → Default apps → Home app
  • Samsung: Settings → Apps → Choose default apps → Home app
  • Xiaomi / Redmi / Poco: Settings → Home screen → Default launcher
  • Oppo / OnePlus / Realme: Settings → Apps → Default app → Home app

3. Go back to the old home screen

  1. Return to Default apps → Home app.
  2. Pick your phone’s original launcher (One UI Home, Pixel Launcher, etc.).
  3. Do this before uninstalling Glitch Launcher so you are not left without a home screen.
